# Week 2 SQL Assignment

This project contains solutions for the Week 2 Introduction to SQL assignment.

## Database

The queries use the `sales` database and cover the `payments`, `orders`, `employees`, `offices`, and `products` tables.

Before running the queries:

```sql
USE sales;
```

## SQL File

The solution queries are available in [week2_assignment.sql](./week2_assignment.sql).

To run the file in MySQL:

1. Open MySQL Workbench or another MySQL client.
2. Connect to the database server.
3. Select the `sales` database.
4. Open `week2_assignment.sql`.
5. Execute the queries.
